# Wanderly Frontend Application

React + Vite frontend for the **Wanderly / Sahasa** Travel Platform.

## Features

- **100% Visual Preservation**: Exact Parchment & Terracotta design system, Cormorant Garamond & Playfair typography.
- **REST API Integration**: Connected to Express backend endpoints (`/api/destinations`, `/api/packages`, `/api/hotspots`, `/api/search`, `/api/bookings`, `/api/reviews`, `/api/newsletter`, `/api/contact`, `/api/admin`).
- **Interactive Auth UX**: Login, registration, profile editing, and booking management.
- **Server Price Calculation**: Server calculates real booking totals when submitting reservations.
- **Admin Dashboard**: Operations console at `/admin` for revenue analytics, bookings verification, user list, and inquiry tickets.

---

## 🚀 Quick Start Guide

```bash
cd frontend
npm install
npm run dev
```

The frontend will run on `http://localhost:5173`.
